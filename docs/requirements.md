# Requisitos

## Requisitos funcionais

RF01 — O sistema deve permitir cadastrar produtos.
RF02 — O sistema deve permitir registrar entradas.
RF03 — O sistema deve permitir registrar saídas.
RF04 — O sistema deve permitir cadastro de usuários.
RF05 — O sistema deve permitir login de usuários.
RF06 — O sistema deve manter um histórico de movimentações.
RF07 — O sistema deve permitir registrar fornecedores.
RF08 — O sistema deve permitir consultar o estoque.

## Requisitos não funcionais

RNF01 — O sistema deve exigir autenticação para acessar funcionalidades protegidas.
RNF02 — As senhas devem ser criptografadas.
RNF03 — O sistema deve impedir operações que resultem em estoque negativo.
RNF04 — Toda movimentação deve preservar a consistência dos dados do estoque.
RNF05 — A API deve validar os dados recebidos pelo cliente.
RNF06 — O sistema deve registrar o usuário responsável por cada movimentação.
RNF06 — O sistema deve gerar um token para cada login com atualização de 15 minutos durante 7 dias.
